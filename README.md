# Liga Prime Level Up

Página estática da Liga Prime Level Up, em português. Os arquivos publicados pelo GitHub Pages estão na raiz do repositório: `index.html`, `styles.css` e `app.js`.

## Publicar no GitHub Pages

No repositório, abra **Settings → Pages**. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` e a pasta `/(root)`, depois clique em **Save**. Aguarde o workflow de publicação terminar. O endereço esperado é https://designmc40-lab.github.io/Liga-Prime-Level-Up/.
